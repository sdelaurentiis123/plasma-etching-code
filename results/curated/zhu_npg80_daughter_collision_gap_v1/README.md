# Oxford NPG80 daughter electron-collision gap

This target-free audit ranks the neutral species omitted from the Oxford
two-term electron collision basis at each conserved absorbed-power state. It
also distinguishes daughter species that have scalar electron-rate regressions
in the heavy chemistry from species that are completely transparent to
electron impact.

At the conditional 120 W state, the energy-resolved EEDF basis contains only
12.95% of neutral pressure. HF alone carries about 59.93%. Installing a
complete, swarm-checked HF collision set is therefore the first closure task;
adding more field range to the parent-only solver is not a physical substitute.
The composition will change when that closure is installed, so this is a
leverage ranking rather than a frozen prediction.
